Installation

Get started in seconds

$ pip install nusantarascan
$ git clone https://github.com/Lutfifakee-Project/NusantaraScan.git
$ cd NusantaraScan
$ pip install -r requirements.txt
$ python main.py --help

Usage Examples

Simple commands, powerful results

# Basic analysis
$ nusantarascan notepad.exe

# RAT detection with YARA rules
$ nusantarascan suspicious.exe --yara nusantarascan/signatures/yara_rules/rat_rules

# Full deep analysis
$ nusantarascan malware.exe --deep --packer --graph --vt

# Recursive scanning
$ nusantarascan ./malware_samples/ --recursive

# Export HTML report
$ nusantarascan file.exe --output report.html --format html

Community YARA Rules

Integrate with the Yara-Rules repository

# Clone community rules
$ git clone https://github.com/Yara-Rules/rules.git \
nusantarascan/signatures/yara_rules/community

# Scan with all community rules
$ nusantarascan suspicious.exe --yara nusantarascan/signatures/yara_rules/community

# Scan specific category
$ nusantarascan suspicious.exe --yara nusantarascan/signatures/yara_rules/community/malware
